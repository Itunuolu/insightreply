Privacy Policy

InsightReply by Hadesh.ai · Last updated August 8, 2026

InsightReply is a user-controlled writing assistant for drafting LinkedIn comments. It never publishes comments automatically or acts on the user's behalf without an explicit action.

How InsightReply works

  1. InsightReply adds an “AI Comment” button to LinkedIn posts.
  2. When the user selects a post, the extension reads that post's author display name, text, and URL.
  3. When the user presses Generate, that selected content and the user's writing preferences are sent to the configured InsightReply backend and then to the configured AI provider to create suggestions.
  4. The user reviews, edits, copies, or inserts a suggestion and remains responsible for pressing Post on LinkedIn.

Data processed

  • Selected website content: the selected post's author display name, text, and URL.
  • Writing preferences: tone, length, language, perspective, and an optional writing profile.
  • Extension settings: stored in Chrome's synchronized extension storage.
  • Selected-post state: stored only in Chrome's session storage and cleared with the browser session.
  • Caller IP address: processed by the backend and hosting provider for security and rate limiting.

Use and sharing

Selected post content and writing preferences are used only to provide requested comment suggestions. They are transmitted to the configured backend and its AI provider for that purpose. Hadesh.ai does not sell this data or share it with advertisers. No third-party analytics are embedded in the extension.

Storage and retention

The InsightReply backend does not use a database to store selected posts. Application logs contain request metadata such as route, status, and latency and deliberately exclude post content and writing-profile text. The hosting provider and AI provider may process limited technical or request data under their respective service terms and retention policies.

User controls

  • Clear Selected Post removes the current post from session storage.
  • Clear Settings resets stored extension preferences.
  • Removing the extension removes its extension-scoped browser data.
  • Users should avoid selecting confidential information for AI processing.

What InsightReply does not do

  • It does not automatically publish comments.
  • It does not collect LinkedIn passwords, cookies, private messages, connections, or profile history.
  • It does not crawl profiles, scroll the feed, bulk-generate comments, or simulate activity.
